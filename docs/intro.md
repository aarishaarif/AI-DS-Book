# Welcome to the AI & Data Science Learning Book

This book is an **independent educational project** designed to guide you from the fundamentals of Python to the frontiers of Agentic AI. It is built as a modern Docusaurus-based website with a strict, book-grounded RAG chatbot.

## What You Will Learn

This book covers nine progressive modules:

1. **Python Foundations** — Variables, control flow, functions, and data structures
2. **Python for Data Science** — NumPy, Pandas, and Visualization
3. **Statistics and Mathematics for ML** — Probability, distributions, and linear algebra
4. **Machine Learning** — Supervised, unsupervised, and model evaluation
5. **Deep Learning** — Neural networks, backpropagation, and architectures
6. **MLOps** — Pipelines, model serving, and monitoring
7. **Big Data and Cloud Computing** — Distributed computing and cloud infrastructure
8. **Generative AI and LLMs** — Large language models and their applications
9. **Agentic AI** — Autonomous agents, tool use, and multi-agent systems

## How to Use This Book

- Read **linearly** through each module to build foundational knowledge.
- Use the **[RAG Chatbot](/chat)** to ask questions grounded strictly in the book content.
- Complete the practical **[guided projects](/projects)** to build your portfolio.
- Track your milestones with the interactive **[progress tracker](/progress)**.

## Prerequisites

- Basic computer literacy
- A willingness to write and run Python code
- No prior AI/ML experience required
